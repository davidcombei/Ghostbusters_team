## 4. Lessons (each with the number that proves it)

1. **Only the WebRTC NS pass at p 0.3 cleared the wave rule, and only on the final readout. Its gain is not the pre-registered mechanism.**
   - B4a final: positive, +1.02 [+0.43, +1.60], clean +0.35. The merge was +0.57 [−0.01, +1.17], so its CI touches 0 (`iter01/verdict.json`).
   - Matched carries 0.43 of the merge's +0.57 and 0.55 of the final's +1.02. Matched has no suppressor stage at all (B4a report §2.4: 0 `afftdn` / `anlmdn` / `webrtc` rows in `matched_v1`). The per-set CIs exclude 0 on matched (+1.24 [+0.19, +2.39] / +1.56 [+0.52, +2.65]); heldout's include it (+0.30 [−0.84, +1.51] / +1.04 [−0.20, +2.33]).
