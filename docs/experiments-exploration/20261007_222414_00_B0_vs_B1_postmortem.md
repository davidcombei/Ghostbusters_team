## 2. Misconfigurations (ranked)

- **M1 `--label_smoothing 0.05` x `--ce_weights 0.1 0.9` (spoof=0.1, bona=0.9).** PyTorch weights the smoothing term by every class's weight (`SLS_setup/main_train.py:517-521`; same criterion for dev loss `:591/:594`). Per-sample optimum: spoof -> p_spoof 0.81, bona -> p_spoof 0.003. Hence the shifted boundary, and a dev loss whose floor is 0.20 and which reads 0.53 for a confidently correct model. Never combine label smoothing with asymmetric class weights.
- **M2 Cosine over 30 epochs + `--earlystop_epoch 12` + `--warmup_frac 0.03`.** Warmup = 0.9 epoch, so the best epoch is the warmup epoch; early stop fired at epoch 13 with the cosine never annealed, so there is no final-epoch EMA readout. Set `num_epochs` to the budget actually run, warmup 5%, no early stop on a cosine run.
- **M3 Peak LR 3e-5 / head 3e-4 is too high after warmup** for full fine-tuning (monotone decline, train acc 96.7%, noisy EER +6). Roadmap H3.
- **M4 `--keep_topk_by_wf1 7` deleted the last epoch** (epoch 13, only in `last_state.pt["ema"]`). On an 8-epoch screen with top-7 kept this can only drop one epoch, so it is tolerated here; the full run of the winning strategy should protect the final epoch via `--keep_epochs <last>`.
- **M5 Three factors changed at once** (MUSAN, level aug, recipe): B1 vs B0 is not attributable.
- **M6 Top-5 merge of EMA snapshots {1,2,3,4,10}** mixes warmup-phase weights with an overfit epoch.
- **M7 Minor (not touched in this wave):** `lr_min` is a multiplier so the head floor is 1e-5; grad norm is not logged; early-stop message prints dev loss; level aug runs after the codec; level target -38..-27 dBFS is below any eval level.
